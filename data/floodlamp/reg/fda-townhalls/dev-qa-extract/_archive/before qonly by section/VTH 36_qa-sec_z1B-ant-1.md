QA Block 1:  What are the FDA's recent authorizations and current highest priorities for COVID-19 test development?
CLARIFIED ANSWER: The FDA has recently authorized several new tests and capabilities: 1) Additional pooling authorizations for identifying asymptomatic patients, particularly useful in low-prevalence screening settings like universities and workplaces. Tests can be used off-label for asymptomatic screening if not specifically limited to symptomatic patients. 2) New home collection kits, including the first home collection for a combined SARS-CoV-2 and flu panel test. 3) A new rapid antigen test and additional serology tests. The FDA's current highest priorities for both review and development are: point-of-care tests, home collection kits, home testing opportunities, panel tests, and extremely high-throughput systems for efficient large-volume testing.

QA Block 2:  What are the FDA's requirements and pathways for sharing validation data when multiple test developers want to use the same LAMP primer set for COVID-19 testing, particularly regarding inclusivity analysis and cross-reactivity studies?
CLARIFIED ANSWER: The FDA offers two main pathways for leveraging shared test validation data: 1) Individual kit authorization with right of reference - A developer can obtain their own EUA and give rights to others to reference their validation data, though kit developers would still need their own authorization. 2) Open method authorization like SalivaDirect - The original developer can designate which labs can use their method under their EUA. Both pathways allow for shared primer sets and reduced duplicate validation, particularly when using identical components and catalog numbers. The SalivaDirect model uses CDC-authorized primers available from approved vendors.

QA Block 3:  What additional validation requirements apply when test developers using the same primer set and LAMP master mix want to implement different sample purification methods (e.g., class mill vs magnetic bead-based), and how does the right of reference work for separate EUAs in this scenario?
CLARIFIED ANSWER: The FDA requires additional validation data for any new test components or methods not covered in the original EUA, such as different purification methods. Test developers can grant each other rights of reference with specific limitations or for their entire EUA. Each developer can maintain their own independent EUA with control over their designations while cross-referencing each other's assays. When core components remain the same, there can be synergy in reducing duplicate validation, but any new elements or changes require separate validation data for FDA evaluation.
