QA Block 2
CLARIFIED QUESTION: Can a primer set for colorimetric LAMP-based assays be used by multiple developers to avoid duplication in validation, and what are the FDA's guidelines?
CLARIFIED ANSWER: Developers can successfully consolidate on a primer set and issue a right of reference for others to use it, reducing duplication. There are two primary pathways: (1) obtaining your own test authorization and allowing others to copy using a right of reference, or (2) creating an open-source method similar to Yale's SalivaDirect model, where the authorized method can be used by designated laboratories. If components are identical across tests, duplicative validations may not be needed. Changes, however, may require additional validations.

QA Block 3
CLARIFIED QUESTION: If two test developers consolidate on a primer set and master mix but use different activation buffers or purifications, will they need to perform additional validations, and how does the FDA handle rights of reference between EUAs?
CLARIFIED ANSWER: If a developer makes changes not covered by the original test (e.g., different purification methods), FDA may require additional validation to assess the impact of those changes. Developers can provide rights of reference to others under an EUA, which can be fully or partially limited based on what the original authorization covers. Tests with identical core components can reduce duplication of the validation effort, but new elements must still be reviewed.
