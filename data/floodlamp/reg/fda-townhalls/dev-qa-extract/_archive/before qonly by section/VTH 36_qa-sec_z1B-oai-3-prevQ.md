QA Block 8
CLARIFIED QUESTION: What is the FDA’s guidance on establishing a primer set for LAMP assays and leveraging authorization pathways for open-source test development?
CLARIFIED ANSWER: The FDA supports pathways for leveraging data on test performance for LAMP-based assays. Developers seeking authorization have two main options: (1) obtaining individual test authorization and providing a right of reference to others to duplicate the test, or (2) using a model like Yale's SalivaDirect, where an authorized method allows the test sponsor to designate which labs can use it under the same EUA. Components such as primers and probes may be chosen based on previously authorized suppliers and catalog numbers. Changes to the test may require additional validation.

CLARIFIED ANSWER: Developers using the same primer set and LAMP master mix can avoid repeating some validations if their components and processes match.
