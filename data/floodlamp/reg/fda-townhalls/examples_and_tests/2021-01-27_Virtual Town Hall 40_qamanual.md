QUESTION: I heard earlier that negative samples and fresh samples are also required. Is this correct? Additionally, if they're using proprietary transport media, is it still necessary to demonstrate the low risk of erroneous results using this media versus a dry swab?
ANSWER: If you are using a new transport media, it must be demonstrated that it does not result in inaccurate results and preserves the target properly. For a device using a new transport media, we need data showing it performs equivalently to UTM. Banked samples can be used for the study, but some fresh samples are required to validate performance. If your test is in a proprietary media, a full fresh prospective enrollment study with this media is needed for submission. The use of different media for validation could impact the study, so it’s crucial to have a consistent approach in the transport media used.
